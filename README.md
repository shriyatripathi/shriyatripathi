### About Me

I'm a software engineer working mainly in **quantitative finance, data science and machine learning**. My interests sit where mathematics meets markets — stochastic processes, market microstructure, game theory and statistical modelling.

### Selected Work

**[math_and_finance](https://github.com/shriyatripathi/math_and_finance)** — Quantitative finance research monorepo
Limit-order-book microstructure and stochastic-volatility option pricing, as two installable Python packages. Includes FI-2010 benchmark analysis with chronological validation and leakage controls, Heston pricing via COS Fourier expansion and Monte Carlo, bounded calibration, and delta-hedging experiments.
`Python` · `NumPy` · `SciPy` · `scikit-learn`

**[Trading-Matching-Engine](https://github.com/shriyatripathi/Trading-Matching-Engine)** — Exchange matching engine
A Price-Time Priority (FIFO) matching engine grounded in exchange-design literature, with a REST API and a React order-book frontend.
`Python` · `React` · `Vite` · `Tailwind`

**[Fashion-Product-Recommender](https://github.com/shriyatripathi/Fashion-Product-Recommender)** — GenAI recommender
Contextual apparel recommendations using vector embeddings and similarity search, aimed at reducing the 24.4% online apparel return rate.
`LlamaIndex` · `Hugging Face` · `AstraDB`

**[object_detect](https://github.com/shriyatripathi/object_detect)** — Drowsiness detection
Real-time drowsiness detection with a fine-tuned YOLOv5 model, from images, video and live webcam.
`PyTorch` · `YOLOv5` · `OpenCV`

**[AI](https://github.com/shriyatripathi/AI)** — Agent evaluation tasks
Containerised coding-agent benchmark tasks in the Terminal-Bench format, with sandboxed environments and hidden verification suites.
